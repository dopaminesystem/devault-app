# Community-first vault product over personal bookmark clone

Devault will be a community-first knowledge vault, not a Raindrop-style personal bookmark manager clone. We will borrow mature retrieval mechanics such as metadata search, tags, highlights, duplicate warnings, import/export, and content-type filters, but those features should strengthen shared vaults, curator workflows, Discord publishing, and community access rather than pull the product toward a private personal library.

Considered alternatives were cloning Raindrop's personal-first feature set or building only a minimal shared bookmark tool. The chosen direction keeps Devault differentiated around shared curation while still giving users serious retrieval quality over time.
